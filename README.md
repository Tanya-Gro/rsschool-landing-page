# Landing Page

## О проекте
Учебный проект курса: адаптивный двухстраничный сайт кофейни Coffee House, свёрстанный по готовому макету Figma. Проект состоит из двух частей: вёрстка с темами и интерактивность на чистом JavaScript.


Макет: [Coffee House](https://www.figma.com/design/yuc5s9NCc4jENkk5LdFfvX/Coffee-House-2026Q3?node-id=0-1).

Текст задания: [Landing Page Task](https://github.com/rolling-scopes-school/tasks/tree/master/fullstack-engineering/tasks/landing-page).

## Функциональность

-  **Бургер-меню** — открытие/закрытие навигации на мобильных экранах.
    
-  **Слайдер / карусель** — на главной странице (например, секция с предложениями или отзывами).
    
-  **Переключение категорий** в каталоге и **отображение дополнительных карточек** (кнопка «Показать больше» / фильтр по категории).
    
-  **Модальное окно** с информацией о выбранной карточке.
    
-  **Выбор параметров карточки** (например, размер: S / M / L) с **динамическим обновлением** связанной информации (цена, объём) в модальном окне **без перезагрузки страницы**.

## Технологии
HTML (семантическая вёрстка)

CSS (Flexbox, Grid, адаптивность, CSS-переменные для тем), Responsive Design

JavaScript, DOM, localStorage

Работа с макетом в Figma
